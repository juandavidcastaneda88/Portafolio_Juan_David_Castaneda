# Portfolio - Juan David Castañeda

Este repositorio contiene el código fuente del portafolio personal de **Juan David Castañeda**, un Desarrollador Full Stack / Junior en formación apasionado por la tecnología, el desarrollo web.

El proyecto presenta un diseño visualmente refinado con un esquema de colores oscuro (Dark Mode), tipografía elegante y una estructura moderna orientada a mostrar habilidades, proyectos y experiencia técnica.

## 📁 Estructura del Proyecto

La carpeta principal `PORTAFOLIO_JUAN_DAVID` se organiza de la siguiente manera:

- **Documentos Raíz:**
    - `index.html`: Página principal del portafolio. Incluye las secciones de "Sobre mí", "Skills", "Proyectos" y un formulario de contacto.
    - `collage.html`: Una galería visual interactiva.
    - `team-developer.html`: Sección dedicada a presentar al equipo de desarrollo asociado a sus proyectos.
    -  FIGMA: Donde se puede visualizar el contenido realizado en Figma.

- **📁 css/**: Contiene las hojas de estilo que dan vida al diseño.
    - `style.css`: Estilos principales (variables, layout, tipografía y animaciones de scroll).
    - `collage.css`: Estilos específicos para la disposición y efectos de la galería de imágenes.
    - `team-developers.css`: Estilos para las tarjetas y presentación de los miembros del equipo.

- **📁 img/**: Recursos visuales del sitio.
    - `hoja-de-vida-juan-david-castaneda.pdf`: Currículum vitae descargable.
    - `David_imagen.jpg`: Fotografía de perfil del desarrollador.
    - `corazon.png`, `Leopardo.png`: Recursos gráficos utilizados en el collage y en las secciones del equipo.

## 🛠️ Tecnologías Utilizadas

- **Frontend:** HTML Y CSS.
- **Tipografías:** Integración de Google Fonts (*Playfair Display*, *DM Sans*, *JetBrains Mono*).
- **Animaciones:** Intersection Observer API para efectos de revelado al hacer scroll y animaciones CSS nativas.
- **Herramientas de Diseño:** Figma (vinculado en el menú de navegación).

## 🚀 Características Destacadas

1.  **Diseño Responsivo:** Adaptado para una visualización óptima en dispositivos móviles y de escritorio.
2.  **Efectos Visuales:** Uso de filtros de escala de grises, transiciones suaves y efectos de iluminación al pasar el mouse (hover).
3.  **Sección de Proyectos:** Enlaces directos a repositorios de GitHub y prototipos en Figma.
4.  **Formulario de Contacto:** Estructura completa para la recepción de mensajes y archivos adjuntos.

## 💻 Instalación y Uso

Para visualizar el portafolio localmente:
 
1.  Descarga el proyecto en Git_HUB
2.  Navega por el Visual_Studio
3.  Oprime el boton  de Go Live
4.  Entraras al proyecto que puedes ver los avances.
